Library

Panduan Pakai di Google Flow

  1. Buka Google Flow
    Masuk ke labs.google/fx/tools/flow dengan akun Google kamu, lalu buat project baru.
  2. Set model & rasio
    Pilih model Gemini Omni Flash, aspect ratio 9:16, dan resolusi 720p. Untuk uji coba cepat, pakai 360p supaya hemat poin.
  3. Upload ingredient
    Pilih mode Ingredients to Video, lalu upload semua foto produk. Kalau ada, upload juga foto karakter sebagai referensi wajah.
  4. Generate Scene 1
    Copy prompt Scene 1 dari aplikasi ini, paste ke kotak prompt Flow, set durasi sesuai yang tertulis, lalu generate.
  5. Lanjut ke Scene 2–6
    Ulangi untuk setiap scene. Blok Continuity Lock di setiap prompt sudah identik, jadi wajah, pakaian, dan lokasi akan tetap konsisten.
  6. Gabungkan & tambah musik
    Susun 6 klip sesuai urutan. Tambahkan musik trending kalau perlu di CapCut atau editor lain.
  7. Upload ke sosial media
    Pakai caption dan hashtag dari tab Caption. Sesuaikan dengan platform tujuan.

Tips supaya hasilnya maksimal

  • Kalau wajah masih berubah, upload foto karakter yang jelas di Flow sebagai ingredient. Itu cara paling efektif untuk mengunci wajah.
  • Kalau dialog terpotong, pendekkan narasi. Model menolak bicara kalau kalimatnya tidak muat dalam durasi klip.
  • Mulai dari 360p untuk draft, lalu upscale ke 720p kalau sudah cocok. Biaya poin jadi jauh lebih hemat.
  • Perbaiki dengan obrolan, bukan generate ulang. Di Flow kamu bisa bilang "cahayanya lebih hangat" atau "perlambat sedikit".
  • Jangan pakai teks panjang di layar. Teks pendek jauh lebih rapi hasilnya.

Pengaturan

Analisis Gambar dengan AI

Aplikasi ini berjalan tanpa AI pun sudah lengkap — kategori produk ditebak dari kata kunci. Kalau kamu mengaktifkan analisis AI, foto produk akan benar-benar dilihat: bentuk kemasan, warna, material, dan tulisan pada label ikut masuk ke prompt. Hasilnya prompt jauh lebih spesifik.

Memeriksa status…

Hanya model yang bisa membaca gambar. Angka pengganda biaya ada di daftar profil di bawah.

Profil API

Kamu bisa menyimpan lebih dari satu konfigurasi API dan berpindah kapan saja. Yang aktif langsung dipakai — tidak perlu menjalankan ulang server.

Tambah profil API

Harus diawali http:// atau https://. Server memanggil {Base URL}/chat/completions.

Key dikirim sekali ke server lokal dan disimpan di mesin ini. Tidak disimpan di browser, dan tidak pernah dikirim balik ke halaman.

Dipisah koma. Ini pembatas keamanan: browser hanya boleh memakai model dalam daftar ini. Kosongkan untuk memakai model vision saja.

Cara kerja & keamanan

  • Key disimpan di server, bukan di browser. Disimpan di _ai-profiles.json pada mesin ini. Browser tidak pernah menerima key-nya kembali — hanya versi tersamarkan.
  • Berkas itu tidak bisa diunduh. Server statis menolak semua path berawalan _, dan berkasnya juga sudah masuk .gitignore sehingga tidak ikut ter-commit.
  • Ganti profil tanpa restart. Konfigurasi dibaca ulang setiap permintaan, jadi menyimpan atau mengaktifkan profil langsung berlaku.
  • Lebih dari satu profil. Berguna untuk memisahkan gateway murah (untuk uji coba) dan gateway mahal (untuk produk yang sulit dikenali), atau untuk berpindah saat kuota satu gateway habis.
  • Fallback berlapis. Bila belum ada profil aktif, server memakai nilai di .env. Bila keduanya kosong, analisis AI mati dan aplikasi kembali ke heuristik kata kunci — tetap menghasilkan 6 prompt.
